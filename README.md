# Rosalind Python Trainings

My solutions for Rosalind bioinformatics problems.

Cell & Molecular Biology undergrad. Using Rosalind to build Python skills for research and job prep.

## Structure

Each Rosalind route has its own folder:

```text
python_village/
bioinformatics_stronghold/
bioinformatics_armory/
algorithmic_heights/
textbook_track/
```

Problem files are named by Rosalind ID, e.g. `ini1.py`, `dna.py`, `rna.py`.
